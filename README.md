# Лес Сургут • первая версия сайта

Индивидуальная реализация по ТЗ от 03.11.2026. Без готового шаблона. HTML, CSS и JavaScript, адаптация от 320 px, оригинальный логотип, реальные фотографии и видео комплекса.

## Открыть и изменить

- `npm install`, затем `npm run build` и `npm run dev`.
- Открыть http://127.0.0.1:4173/.
- Готовые файлы для обычного статического хостинга находятся в `dist/client/`.
- Исходник страниц: `build.mjs`; стили и поведение: `src/styles.css`, `src/app.js`, `src/editor.js`.
- Исходные изображения и шрифты находятся в `assets/`; сборка не изменяет и не удаляет их.
- Контент: `content.json`. После ручных изменений выполнить `npm run build`.
- С сайта можно открыть `/editor/`: редактор цен, контактов, фото обложек и календаря. Он сохраняет локальный черновик, открывает предпросмотр с `?draft=1`, импортирует и экспортирует `content.json`. Для общих изменений надо заменить этот файл на хостинге. Это не серверная CMS. Доступа к заявкам и секретов в редакторе нет.
- Новые фото сначала добавить в `assets/` в WebP, затем указать имя файла в редакторе. Для подтверждённых фотографий домов в редакторе есть визуальный выбор обложки и галереи.

## GitHub Pages

Production опубликован по адресу `https://vladosikkk.github.io/les-surgut-site/` из ветки `main` отдельного репозитория статической сборки. Команда production-сборки:

`SITE_URL=https://vladosikkk.github.io/les-surgut-site SITE_BASE_PATH=les-surgut-site SITE_NOINDEX=0 npm run build`

`SITE_BASE_PATH` добавляет префикс проекта ко всем локальным ссылкам, включая `srcset`, динамические фотографии, шрифты и `content.json`.

## Поведение

Форма проверяет даты, вместимость и телефон и отправляет заявку через `/api/booking` (Cloudflare Pages Function). От спама защищают Turnstile, honeypot и минимальное время заполнения. Function ничего не сохраняет: заявка передаётся менеджеру через Telegram Bot API. Если серверная отправка недоступна, сайт сохраняет рабочий резервный сценарий — составляет сообщение и открывает проверенный контакт комплекса в MAX, WhatsApp или Telegram. Обратный звонок и видеообзор доступны без обязательных дат.

Календарь поддерживает занятые и подтверждённо свободные ночи, выбор периода, прошлые даты и проверку пересечения занятости. Исходных данных о занятости нет: даты помечены «уточнить». `busy` и `free` заполняются по фактическим данным. Дата выезда не считается занятой ночью.

Карта загружается после согласия. Метрика включается только после заполнения `analytics.yandexMetrikaId` и согласия пользователя. Webvisor выключен. События: `message_prepared`, `messenger_opened`, `video_opened`.

## Перед клиентским запуском

1. Подтвердить цены, число спальных мест и соответствие фото каждому дому. Цены «от» и максимальное число гостей взяты из публичных карточек объектов; правила оплаты и отмены не выдумывались.
2. Загрузить реальную занятость. Сейчас она не объявляется свободной автоматически.
3. Добавить номер Метрики, если аналитика нужна.
4. Для серверной отправки заявок заполнить секреты Cloudflare Pages, перечисленные ниже, и дополнить сведения об операторе данных при необходимости.

## Cloudflare Pages

- Git integration: приватный GitHub-репозиторий, production branch `main`.
- Framework preset: `None`.
- Build command: `npm run build`.
- Build output directory: `dist`.
- Node.js: 22.
- Functions автоматически берутся из каталога `functions/`.

Переменные проекта:

- `TURNSTILE_SITE_KEY` — публичный site key виджета Cloudflare Turnstile.
- `TURNSTILE_SECRET_KEY` — зашифрованный secret key Turnstile.
- `TELEGRAM_BOT_TOKEN` — зашифрованный токен бота, который отправляет заявки менеджеру.
- `TELEGRAM_CHAT_ID` — зашифрованный ID чата менеджера.
- `TURNSTILE_HOSTNAMES` — необязательный список разрешённых доменов через запятую; без него проверяется текущий домен запроса.

Три секретных значения задаются в Cloudflare Pages → Settings → Variables and Secrets с включённым Encrypt. В Git они не хранятся. После настройки выполнить новое развертывание.

## Проверка

16 страниц, включая `/weddings/`; адаптивность проверяется на ширинах 320–1920 px. Команда `npm run check` проверяет JavaScript, внутренние ссылки на ресурсы, обязательные страницы, лимит Cloudflare Pages 25 МиБ и логику Pages Function. Браузерные сценарии отдельно проверяют меню, форму, галереи, отзывы, возврат фокуса и реальное воспроизведение всех видео.
