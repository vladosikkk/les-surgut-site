Единый источник — массив `hotDates` в `content.json`. Сейчас массив пуст: тестовые даты не включены в чистую и подготовленную к публикации сборку.

Реализовано:

## 5. Управление заказчицей

В `/editor/` можно подготовить, проверить и локально просмотреть предложения. Работают добавление, редактирование полей, автоматический расчёт скидки, отключение, отметка «забронировано» и удаление из черновика.

Для реальной публикации подготовлен ручной workflow `.github/workflows/manage-hot-dates.yml`. Он запускается только авторизованным пользователем GitHub, валидирует данные общей логикой, меняет `content.json`, создаёт обычный коммит и выполняет обычный `git push` без force. Пароли, PAT и приватные API-ключи в коде отсутствуют.

После публикации ветки потребуется однократная настройка репозитория: предоставить заказчице доступ к репозиторию и разрешить GitHub Actions `Read and write permissions`. Workflow должен находиться в основной ветке — до публикации локальной сборки на публичном сайте его ещё нет.

Синхронизации с внешней системой фактической занятости нет. Поэтому акция не объявляет дату свободной и всегда предлагает подтвердить доступность у менеджера.

## 12. Локальный просмотр

Из корня исходников:

```sh
SITE_BASE_PATH=les-surgut-site npm run build
mkdir -p /tmp/les-preview
ln -sfn "$PWD/dist/client" /tmp/les-preview/les-surgut-site
python3 -m http.server 4173 --bind 127.0.0.1 --directory /tmp/les-preview
```

Открыть `http://127.0.0.1:4173/les-surgut-site/`.

## 13. Публикация после подтверждения

1. Повторить чистую сборку и `npm run check`.
2. Убедиться, что `content.json` содержит `"hotDates": []`, если заказчица ещё не дала реальные даты.
3. Синхронизировать `dist/client/` с локальной веткой `codex/final-launch-build-20261128` и закоммитить.
4. Обновить локальную `main` из `origin/main`, выполнить fast-forward merge подготовленной ветки и обычный `git push origin main` без force.
5. Дождаться GitHub Pages и повторно проверить публичный сайт, четыре дома, общую галерею и GitHub Actions.

До отдельного подтверждения шаги 4–5 не выполняются.
