# LES SURGUT Final Launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Подготовить локальную версию LES SURGUT с 101 упорядоченной фотографией четырёх домов и управляемой системой «Горячих дат».

**Architecture:** Существующий статический генератор продолжает строить страницы из `content.json`; новый модуль чистой логики фильтрует акции в браузере и тестах. Существующий редактор расширяется, а безопасная публикация предложений подготавливается через ручной GitHub Actions workflow.

**Tech Stack:** Node.js ESM, vanilla HTML/CSS/JavaScript, GitHub Pages, GitHub Actions, WebP/cwebp.

**Spec:** `docs/superpowers/specs/2026-11-28-final-launch-design.md`

## Global Constraints

- Не публиковать до отдельного подтверждения.
- Не менять обычные тарифы, тексты, видео, контакты, URL и существующую логику бронирования без необходимости.
- Сохранять `/les-surgut-site/`, исходные пропорции и точный порядок фотографий.
- Не размещать секреты, токены и приватные ключи в коде.

## Review Focus

- Граница «сегодня + 7 дней» и смена суток по `Asia/Yekaterinburg`.
- Просроченные, забронированные и вручную отключённые предложения не отображаются.
- Акционная цена не может быть отрицательной или выше обычной.
- Галереи не смешивают дома и не меняют заданный порядок.
- Статический GitHub Pages не выдаёт локальный черновик за опубликованные данные.
